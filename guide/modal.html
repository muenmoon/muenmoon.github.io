# 弹窗标题

TIP

自定义操作的弹窗标题默认为它的按钮名称modalConfig.customOperationTypes中的title，可通过配置modalTitle更改

<template>
  <BuseCrud
    ref="crud"
    title="人员列表"
    :loading="loading"
    :tablePage="tablePage"
    :tableColumn="tableColumn"
    :tableData="tableData"
    :modalConfig="modalConfig"
    @modalCancel="modalCancelHandler"
    @modalSubmit="modalSubmit"
    @modalConfirm="modalConfirmHandler"
    @rowDel="deleteRowHandler"
    @loadData="loadData"
    @handleCreate="rowAdd"
  >
    <template slot="apply" slot-scope="{row, operationType}">
      <div>
        <p>当前操作类型：{{ operationType }}</p>
      </div>
    </template>
  </BuseCrud>
</template>

<script>
  const res = {
    data: [
      { name: "张三", sex: "1", age: 18 },
      { name: "李四", sex: "2", age: 19 },
    ],
    total: 2,
  };
  export default {
    name: "DumiDocVueIndex",
    data() {
      return {
        tableData: [],
        tableColumn: [
          {
            field: "name",
            title: "姓名",
          },
          {
            field: "sex",
            title: "性别",
            formatter: ({ cellValue }) => {
              return cellValue === "1" ? "男" : "女";
            },
          },
          {
            field: "age",
            title: "年龄",
          },
          {
            field: "birth",
            title: "出生年",
          },
        ],
        params: { name: "", sex: "", age: "" },
        loading: false,
        tablePage: { total: 0, currentPage: 1, pageSize: 10 },
      };
    },
    computed: {
      modalConfig() {
        return {
          addBtn: true,
          addTitle: "这是新增操作的标题",
          editTitle: "这是编辑操作的标题",
          viewTitle: "这是查看操作的标题",
          formConfig: [
            {
              field: "name",
              title: "姓名",
            },
            {
              field: "sex",
              title: "性别",
              element: "el-select",
              defaultValue: "1",
              props: {
                placeholder: "请选择性别",
                options: [
                  {
                    label: "男",
                    value: "1",
                  },
                  {
                    label: "女",
                    value: "2",
                  },
                ],
              },
            },
            {
              field: "age",
              title: "年龄",
            },
          ],
          customOperationTypes: [
            {
              //定义操作类型名称
              typeName: "apply",
              title: "发起申请",
              modalTitle: "发起申请的弹窗标题",
              //该操作下弹窗对应内容插槽
              slotName: "apply",
              event: (row) => {
                this.applyBtnClickHandler(row);
              },
            },
          ],
        };
      },
    },
    mounted() {
      this.loadData();
    },
    methods: {
      applyBtnClickHandler(row) {
        //第二个参数：操作类型
        this.$refs.crud.switchModalView(true, "apply", {
          ...row,
          otherInfo: "额外传递给弹窗的数据",
        });
      },
      async loadData() {
        this.loading = true;
        const result = await new Promise((resolve) => {
          setTimeout(() => {
            resolve(res);
          }, 1000);
        });
        this.loading = false;
        this.tableData = result.data;
        this.tablePage.total = result.total;
      },
      rowAdd() {
        this.$refs.crud.switchModalView(true, "ADD");
      },
      modalCancelHandler() {},
      modalSubmit() {},
      modalCancelHandler() {},
      deleteRowHandler() {
        this.$message.info("点击了删除");
      },
      modalConfirmHandler() {},
    },
  };
</script>

# 自定义操作

TIP

当触发自定义操作事件后，如果该事件涉及到弹窗，且弹窗中需要展示相应内容，则需要配置modalConfig.customOperationTypes

modalConfig.customOperationTypes单项配置中，typeName(操作名称)和 slotName(插槽名称)控制着弹窗中对应内容的展示；

在方法：switchModalView中，第二参数则代表着单项配置中对应的 typeName；第三个参数是透传给弹窗用的数据，可以在表格行数据上自行增加；

# 表单布局

TIP

弹窗表单的布局，通过modalConfig.formLayoutConfig进行配置，formLayoutConfig.labelPosition控制表单域标签的位置，包括right/left/top，formLayoutConfig.inline开启行内表单模式；

formLayoutConfig.defaultColSpan则可以用于控制一行多列的控制；
